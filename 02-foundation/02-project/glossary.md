# Глоссарий проекта

## Назначение

Фиксирует значение терминов, чтобы человек, агент и код понимали слова одинаково и не возникал
language drift. Пополняется по мере общения человека с агентом.

## Термины фреймворка Rocket

- **canonical truth** — каноническая правда: содержимое `01-standards` и `02-foundation`.
  Побеждает при конфликте с кодом и операционным состоянием.
- **operational state** — операционное состояние: содержимое `03-execution`. Описывает, что
  делается сейчас, не владеет правдой.
- **dev** — единственная интеграционная ветка и текущее рабочее состояние проекта. То, что
  запускается.
- **claim** — взятие задачи агентом с созданием локального лока, чтобы другой агент не взял ту
  же работу или не залез в те же `owned_modules`.
- **owned_modules** — пути/модули, которые задача меняет. Непересечение owned_modules делает
  параллельную работу безопасной.
- **reconstructability** — свойство документации: по ней можно восстановить и запустить рабочий
  проект.
- **drift** — молчаливое расхождение между намерением, документацией и кодом. Главная проблема,
  против которой работает фреймворк.
- **worktree** — отдельная рабочая копия Git в своей папке; используется для изоляции
  параллельных агентов, чтобы не ломать запускаемый `dev`.
