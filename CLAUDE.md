# CLAUDE.md

Локальные инструкции для Claude Code при работе в проекте на Rocket.

## Язык

Отвечать на русском. Сначала ответ, затем краткое объяснение при необходимости.

## Маршрутизация

Основная точка входа — [AGENTS.md](AGENTS.md). Перед работой следовать его порядку чтения и
правилам.

## Контекст

Использовать только контекст внутри текущего проекта, если человек явно не попросил
cross-repo работу.

## Doc-first

Не менять поведение/код в обход документации. Перед изменением поведения сначала обновить или
явно подтвердить релевантные canonical docs, затем менять код.

## Git

Все операции с Git — локальные. Никогда не пушить в remote без явной команды человека.
Главная рабочая копия всегда на ветке `dev`.
