# Lifecycle документов

## Назначение

Фиксирует правила изменения, замены, архивации и удаления документов Rocket.

## Статусы

- `active` — документ действует.
- `draft` — черновик, не является обязательной правдой до принятия.
- `superseded` — документ заменён другим canonical документом.
- `cancelled` — документ отменён и не должен использоваться как источник правды.

Для ADR используются `proposed`, `accepted`, `superseded`.

## Supersede

Если документ заменяется:

1. старый документ получает статус `superseded`;
2. в нём указывается replacement/superseded_by;
3. новый документ ссылается на superseded документ;
4. индексы обновляются тем же изменением;
5. задачи, которые ссылаются на старый документ, не переписываются задним числом, но новые задачи
   должны ссылаться на replacement.

## Удаление

Удаление canonical документа допустимо только если:

- документ был `cancelled` или `superseded`;
- нет активных задач, которые на него ссылаются;
- index и ссылки обновлены;
- `bb docs-lint` и `bb state-lint` проходят.

Если документ нужен для истории решений, предпочтительно оставить его как `superseded`, а не
удалять.

## Архивация execution

Done-задачи не удаляются в обычном workflow. Если нужен архив, он выполняется отдельной задачей
с явным scope и сохранением traceability task → canonical refs → commit.

## Шаблоны

Шаблоны можно менять без supersede-статуса, если изменение не ломает существующие документы. Если
шаблон меняет обязательный контракт, сначала обновляется соответствующий standard.
