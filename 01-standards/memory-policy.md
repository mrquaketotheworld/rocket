# Политика памяти агента

## Назначение

Определяет, как агент использует durable memory в проектах на Rocket. Память дополняет
документацию, но не заменяет canonical truth.

## Hermes

`pi-hermes-memory` — обязательный pi extension для долговременной памяти агента. Он нужен,
чтобы сохранять устойчивые предпочтения пользователя, проектные соглашения и уроки из ошибок
между сессиями.

## Что сохранять

Агент сохраняет компактные устойчивые факты:

- явные предпочтения и исправления пользователя;
- проектные conventions, которые пригодятся в будущих задачах;
- повторяемые failure/correction/tool-quirk уроки;
- стабильные сведения об окружении.

## Что не сохранять

Нельзя сохранять:

- временный прогресс текущей задачи;
- секреты, токены, приватные данные;
- длинные логи;
- факты, которые уже должны жить в canonical docs;
- догадки без подтверждения.

## Иерархия

Если память конфликтует с текущими файлами проекта или командой пользователя, побеждают:

1. текущая команда пользователя;
2. canonical docs;
3. текущее состояние репозитория;
4. durable memory.

При обнаружении полезного устойчивого факта, которого нет в docs, агент должен либо добавить
его в canonical docs в рамках задачи, либо сохранить в memory только как вспомогательный
контекст, если это не canonical truth.
